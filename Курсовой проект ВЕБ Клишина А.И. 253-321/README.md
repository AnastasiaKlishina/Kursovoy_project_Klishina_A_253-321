# RPG Character Generator

Курсовой проект на Python + SQLite.

Программа позволяет случайно генерировать персонажей для RPG-игр и сохранять их в базу данных.

---

# Возможности программы

- Генерация персонажей
- Случайные характеристики
- Сохранение в SQLite
- Просмотр персонажей
- Удаление персонажей
- Поиск по классу
- Статистика

---

# Используемые технологии

- Python 3
- SQLite3
- Random

---

# Структура проекта

```text
main.py              - основной файл программы

```

# Запуск проекта

## 1. Открыть терминал

Перейти в папку проекта:

```bash
cd character_generator
```

---

## 2. Запустить программу

```bash
python main.py
```

---

# Главное меню

После запуска доступны команды:

```text
1. Сгенерировать персонажа
2. Показать всех персонажей
3. Удалить персонажа
4. Поиск по классу
5. Статистика
0. Выход
```

# База данных

Проект использует SQLite.

Автоматически создаётся файл:

```text
characters.db
```

---

# Структура базы данных

## Таблицы:

- characters
- races
- classes
- weapons

---

# Пример SQL-запросов

## Показать всех персонажей

```sql
SELECT * FROM characters;
```

## Средний уровень персонажей

```sql
SELECT AVG(level)
FROM characters;
```

# Создание .exe файла

Установить PyInstaller:

```bash
pip install pyinstaller
```

Создать exe:

```bash
pyinstaller --onefile main.py
```

Готовый exe появится в папке:

```text
dist/
```
